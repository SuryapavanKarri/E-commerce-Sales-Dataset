Amazon Sales Analysis Using Microsoft SQL Server
Overview
This project analyzes Amazon sales data using Microsoft SQL Server. The objective is to transform raw sales
data into meaningful business insights through SQL queries, database objects, and analytical techniques.
Project Objectives

Import and manage sales data in SQL Server
Perform data analysis using SQL queries
Create Views and Stored Procedures
Apply Window Functions for advanced analysis
Generate business insights from sales data
Tools & Technologies
